## 实际体验流程

1. 今天点击“回忆”或“事项”，直接切换底部入口。
2. 回忆输入普通问题，来源和人物可筛选；时间、来源身份编辑和模型分析选项折叠。模型归纳默认关闭，用户主动开启后依既有配置处理必要资料，可能访问网络。
3. 点击回答中的引用，原生 sheet 展示原聊天上下文或录音依据；录音可用既有播放器播放片段，或打开原转写/标注页面。返回保留查询。来源失效后旧归纳失效，失效片段不继续播放。
4. 事项的“已确认提醒”使用原提醒任务命令完成、改期、取消；聊天跟进仍使用原 chat.followup 命令。操作保存在原 outbox，网络暂不可用时显示待同步；原 revision 冲突和系统日历权限/外部修改/重试提示保留。
5. 需要用户判断的审核可从事项或管理进入；人物可从回忆或管理进入。未知身份不自动创建新审核任务。关联、解除和拒绝仍使用既有 catalog version、依据及操作编号。
6. 今天只展示今日可用缓存；未生成/未同步、模型失败、部分覆盖分别提示，并保留原文浏览入口。

没有新人物状态、任务表、日历规则、记忆规则、同步通道或自动模型调用。本轮不扩大人物深度编辑和工程管理页重构。
