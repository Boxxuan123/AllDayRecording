## 任务路径

|任务|真实默认路径|主操作与范围|
|---|---|---|
|已知人物样本|收件箱 → 原生审核页 → 完整试听 → 判断 → 下一条|采纳当前 review/prototype，正常流程 3 次点击（含进入），不进通用标注页|
|未知声音|进入 → 依据 → 勾选完整原句 → 完成选择 → 人物选择器 → 选人 → 保存|三句选两句共 8 次点击，一次本地事务；不批准整轨道/聚类、不采纳声纹|
|历史授权|已采纳样本 → 可选重听 → 单个撤回 → 确认|无音频仍能撤回，不修改原句人工事实|
|可选纠正|更多 → 依据选择 → 共享人物选择器/保存|复杂逐句处理才进入已有标注页，父级导航位置保留|

待处理 selector 排除 accepted_grant/history，供首页、录音、人物和审核列表共同使用。任务组数与组内样本数分开显示。精确证据按 media/capture 时间轴、稳定句 ID 和版本映射；一个样本的 5 个窗口不等于同轨道 81 句。缺失或歧义映射不猜测，仍保留完整音频审核与上下文入口。

本地已保存事实从 SQLite 重读，重开后不重复要求已提交原句。未知声音事务仅修改人物维度，不自动关闭发现任务。纠正后旧样本受待同步/版本保护。暂不确定沿用服务端持久判断/重匹配语义；本轮跳过是纯导航。A 跳过、B 成功后继续 C，末尾可回看 A。

审核明确成功才推进。网络错误保留位置；超时先读取，仍待处理时保留未知状态并阻止重复提交；已提交但写缓存失败只读重试。对象消失不冒充本次成功。完整试听继续校验对象、audition_key、每个窗口及拼接偏移、总长和真实播放器完成；无关刷新保留试听，当前来源/授权改变使旧凭证失效。

## 真机与限制

真实 HarmonyOS 手机运行生产页面、VM、保存用例、SQLite 和播放器；写操作只使用独立验收数据库及合成人物、句子、音频。远程端口是受控替身，不将此验收冒充真实电脑网络端到端测试。真实缓存仅只读检查，未向真实录音/人物保存标注或执行采纳/撤回。隔离数据库已删除，正式应用恢复。

首屏问题明确；已知页唯一强调主动作是采纳；未知页是确认明确所选原句；历史页是撤回单个授权。选择器独立，不挤动正文；关闭保留父页选择，手势返回触发草稿确认。正常字体下播放与底部决定同屏；无全局同步悬浮遮挡、默认无调试动作清单。

真机发现并修复跨样本依据数量未更新的问题。合成数据真机图册随会话交付，截图不进入公开仓库；包含收件箱、试听前/后、继续下一条、三句选两句、重开后的事实、人物选择器/键盘、返回确认、无音频历史撤回、断网停留、队列末尾。

按用户后续要求停止继续检查大字体与明暗主题，并恢复原设置。真实电脑超时/多端并发未在用户数据上执行；由生产 VM/ASR 测试覆盖。配套证据映射需电脑端加载本轮 ASR；旧服务端保守降级。未知超时后若电脑始终返回同一待处理样本，不能证明未执行时不放开重复提交。复杂逐句分支的代码接入与标注回归已通过，但本轮隔离入口未挂载其完整目的页，因此不声称该分支完成了新的真机闭环验收。
