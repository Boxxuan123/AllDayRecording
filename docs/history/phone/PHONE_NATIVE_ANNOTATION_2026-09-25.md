## 页面关系与实现

`人物/声音入口 → 当前范围片段列表 → 单条查看/标注`。时间线和审核中点击的原句直接进入单条页。生产 HdsNavigation 的 NavPathStack 管理 AnnotationListPage / AnnotationPage，两者使用 HdsNavDestination。旧大型 SpeakerAnnotationPanel 已删除；bindSheet 仅用于独立人物、声音和详情选择层。

入口区分已知人物和未确认声音。人物按真实 annotationPersonId 聚合；未知声音按会话与轨道分组，缺失轨道时保留单句，不根据显示名称合并。组内数量与名称变化会更新行，打开时取最新范围。审核保持紧凑入口，不要求清空所有未知声音。

范围列表拥有选中态分段、搜索、分页、批量和跨筛选多选。全部完成的范围默认显示已标注。单条默认只呈现正文、播放、人物/声音设置行与保存；完成句先展示具体完成维度及“修改标注”。正文按实际测量决定是否显示展开，媒体控件为真实播放/停止及总时长，没有模拟进度。

选择人物或声音后只修改父级草稿并关闭选择器；新建姓名在最终本地保存事务前不落库。新建子界面取消恢复原选择，选择器返回/遮罩/下拉不退出编辑器。单条系统返回、标题返回、边缘返回统一经过草稿检查。保存中及已保存待读取期间不能重新打开人物/类型编辑。系统杀进程不在确认框保护范围内。

设置行显式使用 @Prop 保持当前值响应，选择勾号及分段样式直接读取状态，避免局部 Builder 参数缓存旧值。沿用既有主题资源，16 vp 水平留白、17 fp 正文、60 vp 设置行、48 vp 主按钮最小高度。启用 app 字体跟随系统配置，不强行缩字。

## 保留的业务边界

- 完成状态仍来自 PhoneV3AnnotationState 的持久化人工事实；没有新增 UI 完成标志作为业务依据。resultMode 仅控制查看/编辑展示。
- 使用现有 saveAnnotation / queueAnnotation 事务，人物和声音仅提交实际选择的维度。预测明确显示为系统建议。取消新建不留人物。
- 本地保存成功后才继续，保存失败保留草稿。保存成功但后续读取失败只提供重读，不重复提交。下一条不自动播放。
- Editor 保存一轮稳定顺序：跳过 A、保存 B 后继续 C；到末尾不回绕到 A，显示剩余项并提供“回去处理”。跳过不落库、不算完成。
- 批量默认零选择，保留跨页、筛选外选择与 2000 条上限。预览使用独立 editor，不改变父列表多选；批量复用同一选择器。
- 刷新不再无条件停止音频。新快照只在当前来源移除/过期、版本/时间范围/本地来源改变，或当前审核样本/授权证据变化时停止并失效旧凭证；换句、退出和主动停止仍停止。无关新录音或快照刷新保留当前试听。
- 声纹完整试听、授权/撤回、回执与投影衔接、冲突处理和版本保护沿用原边界；普通标注没有新增完整试听门槛。

## 真机证据与限制

在连接的 HarmonyOS 真机上采集并查看入口、列表、单条、人物、声音、键盘、结果、批量和完成空态，以及明暗主题与大字体截图。默认逻辑宽度约 376 vp；开启系统大显示尺寸后约 329 vp，字体“超大”约 1.3 倍。实测大字体单条页主操作可见、设置值可换行、两个选择器内容可阅读。测试后恢复原来的深色、标准字体和默认显示尺寸。

实际验证：标题/系统/快速边缘返回草稿提示；选择器取消、系统返回、下拉、遮罩关闭；取消新建保留原说话人和声音草稿；修改后重新打开选择器勾号更新；跨页多选后预览再返回仍保留选择；时间线/审核原句直接打开所点句子，返回原入口和原滚动位置；已全部标注范围默认展示已标注。

设备验收没有保存测试标注、创建测试人物、采纳/撤回声纹或触发测试同步。已有待同步记录保持原状。真实姓名、转写、截图、布局转储、日志均不进入本次公开提交；截图只通过本次会话的实际图片及本地审核包交付。公开文档和相关测试中的原有个人示例改为合成名称。

未验证：第二台物理小屏、系统最大字体 3.2 倍、手表端字体跟随的真实画面、蓝牙/耳机和实际听感、本轮真机持久化保存及真实断网同步。事务及失败行为由隔离 SQLite/宿主/VM 测试覆盖；不把替身音频测试或构建通过当作这些真机项目通过。长正文极端布局仍需更多真实长度样本，不将短正文首屏结论推广到所有内容。
